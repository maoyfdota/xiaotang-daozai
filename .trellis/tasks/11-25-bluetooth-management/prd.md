# macOS 蓝牙管理

## Goal

在 Mac 的岛仔内查看已配对蓝牙设备的状态和可用电量，对受支持设备完成连接／断开，并通过独立提醒获知连接变化及低电量。

## Confirmed Decisions

- D-01：本分支只做 macOS。用户于 2026-11-25 明确：“这个分支只需做mac的”。
- D-02：首版包含独立设备页、状态和可用电量、受支持的连接／断开、键盘断开确认、独立连接变化与低电量提醒，以及 Mac 蓝牙设置回退入口。用户对该完整范围回答“对”。
- D-03：用户要求“不要用子智能体”。后续研究、实现、检查与收尾均由主会话直接完成；不修改全项目的调度配置。

## Requirements

### R-01 设备页面与配置

- 新增“蓝牙”页，列出系统能够枚举的已配对设备名称、类型、连接状态和可用电量；已连接优先，同组稳定排序，同名设备独立识别。
- 有效电量含 0%–100%；无法读取显示“未知”。长名称可查看，长列表全部可访问。
- 区分加载、无设备、正常、部分失败、无权限及蓝牙不可用，并提供刷新。
- 接入已有页面显示、隐藏和排序；迁移保留原页序、可见性、隐藏功能配置和其他用户设置。

### R-02 连接与断开

- 按设备及动作分别判断能力；受支持时提供直接操作，期间显示进度并防止重复请求。
- 系统实际状态确认结果；失败或超时后可恢复操作，有原因提示。音频输出、键盘输入可用性单独实机验收。
- 断开键盘前确认，取消不发送命令；发送前复核设备及能力。
- 切页、收起、外部状态变化、设备移除、晚到结果不会错误完成另一请求。

### R-03 系统设置和权限

- 页面及设置提供“打开 Mac 蓝牙设置”，不支持、失败或系统限制时可回退。
- 无权限与空列表明确区分，提供授权说明与设置入口；不重复请求或自动重置系统权限。
- 对无法枚举或控制的设备准确说明限制，保留已知信息，允许在系统设置继续管理。

### R-04 独立提醒与低电量周期

- 管理独立于连接提醒；关闭提醒后列表及操作继续可用。初次快照建基线，不群发新连接提醒；未知或查询失败不产生虚假断开。
- 低电量有独立开关。已连接、新有效读数 ≤20%、本轮未提醒时提示名称、剩余电量和充电信息。
- 每台设备每轮一次；有效读数 >20% 才重置，重连、改名和应用重启继续去重。实际展示后才记录，排队不算展示。
- 未知、失败、断开和旧 UI 缓存不触发或重置；展示前条件失效则取消。系统缓存滞后时不推测充电恢复。
- 隐藏蓝牙页面不关闭已开启提醒。总提醒关闭时不展示，恢复后按有效数据判断；两个独立开关分别保存与生效。

### R-05 兼容与交付

- 沿用 Apple Silicon 构建、macOS 11.0 部署目标、数据目录及 Mac 窗口约定；未实测的旧系统和设备能力如实记录。
- 使用已有 Mac `.app` 构建和安装入口交付，核对包标识、二进制哈希和进程路径。
- 本任务不增加 Windows 蓝牙功能；必要共享配置变动保持已有 ID 和保存值兼容。

## Out of Scope

新设备搜索配对、忘记设备、系统蓝牙总开关、多主机自动切换与抢连；品牌专属控制、左右耳及充电盒分电量、音频路由自动切换；Windows 功能开发、Intel 扩展、签名公证及分发安装包。

## Risks and Bounded Deferred Items

- 经典蓝牙、BLE 和厂商设备的系统可见性及控制能力不同；不能可靠关联或控制时使用已批准的能力说明与设置回退。
- 部分设备不提供电量，系统缓存可能滞后；按未知或有限能力记录，不用合成数据替代硬件结果。
- 规划时系统报告有四台未连接设备，无已连接设备，尚无真实电量、音频或键盘验收结果。实现时补实机记录，必要的硬件步骤由用户完成。
- macOS 11.0 是已有构建部署目标，接口需核对可用版本；旧系统运行覆盖按实际条件记录。

当前没有未解决的产品范围问题。需求、设计和实施计划完成后，以最新规划摘要取得实施确认。
