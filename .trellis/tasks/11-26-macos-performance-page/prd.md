# macOS 性能页基础采样与趋势

## 目标

在 Mac 版增加系统性能页，提供 CPU、内存、磁盘读写速率、网络收发速率及近期趋势，填补当前 Mac 版没有系统性能页面的缺口。

## 范围与约束

- 只在 macOS 开放；不要求 Windows 兼容。
- 固定使用页面 ID 10、设置页签 ID 16；已有页面 ID 0–9、蓝牙页面 ID 9 和蓝牙设置页签 ID 15 保持不变。
- 采样范围为 CPU 使用率、物理内存使用量、磁盘读写字节速率、网络收发字节速率。趋势保留最近约一分钟的采样。
- 旧配置保留已保存的页面开关和顺序，新性能页追加在顺序末尾；与既有新页面迁移行为一致，新页默认可见。
- 任何接口缺失、读数失败、首次采样或累计计数器重置都显示为不可用，不用 0 代替未知值。计数器差值按真实采样间隔换算。
- 仅页面运行时采样和更新趋势；不新增性能常驻、进程排行、GPU／显存／温度或后台监控设置。
- 不合并不同分支；`origin/main` 仅作行为参考。

## 验收标准

1. Mac 页面 ID 10 可用，蓝牙仍为 9；设置页签 ID 16 可打开性能页设置，蓝牙仍为 15。Windows 不开放 ID 10。
2. 8–10 页旧顺序读入后不变，新页 ID 10 位于末尾；6–10 位旧可见性配置保留原位，并正确迁移新页默认值；11 位新配置可往返读写。
3. 已知累计值差异按实际秒数得出 B/s；无基线、非正间隔和无法解释的计数器回退不产生虚假的零速率。CPU 差值在有效采样间隔内得出 0–100% 使用率。
4. 缺失或失败的 CPU、内存、磁盘、网络值在界面明确显示“不可用”或破折号，趋势图保留缺口而非画成零。
5. 性能页显示四类指标与趋势，最多保留约一分钟样本；不展示 GPU、进程排行或性能常驻入口。
6. Mac arm64 定向测试和 release 编译通过；配置及既有页面导航回归通过。

## 已确认的自动化测试边界

- 页面 ID、平台开放范围及旧配置迁移。
- 累计计数器差值与采样间隔换算。
- 指标不可用状态，不把读取失败伪装为 0。

## 排除项

进程排行、GPU 与显存、GPU 温度、性能常驻组件、2.4G 无线接收器、插件集市／扩展、邮件、AI 额度、音乐兼容，以及跨分支合并。
