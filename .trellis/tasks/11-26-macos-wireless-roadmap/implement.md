## 核心测试清单

1. 电量：0、20、21、100、缺失、非法值、失败、过期、重复读取；查询时间和设备采样时间不混淆。
2. 身份：同名／改名、大小写地址、未知关联、重连前后的读数。
3. 常驻：0／1／2／多台，自动低电量优先，同值稳定，自选断开后恢复，配置重启及旧顺序迁移。
4. 操作：保留现有请求身份、能力复核、键盘确认、单个原生槽、超时与晚到结果检查。
5. 提醒：阈值与恢复、实际显示确认、失败／未知不触发、总开关／独立开关、重启去重。
6. 详情保留电量时效说明，不出现充电状态占位提示。
7. UI：已连接／断开／无权限／空设备／部分失败、深浅色、长名称、滚动、常驻点击路由、缩放及透明边缘。
8. 配置：ID 9／15 不改变，其他隐藏模块设置继续保存，新设置默认关闭且旧提醒状态保留。

## 后续阶段的拆分原则

- 性能：基础指标和趋势 → 进程排行／常驻 → 有硬件证据的 GPU 指标。
- 停靠：单屏底部 → 多屏移动和缩放 → 接缝／可用区域 → 可验证的截图隐藏场景。
- 日历：本机日程与编辑 → 日期／农历常驻 → 用户确需的远程日历连接和修复。
- 置物架／剪贴板：原生能力与数据流 → 页面开放 → 保持展开和拖出恢复。
- 关于／诊断／更新：感谢墙 → 诊断导出 → 更新提示 → 单独批准范围内的应用替换／分发设计。

每一小步只运行相关验证；已完成部分见 progress.md，软件检查与已有失败基线见 validation.md。
